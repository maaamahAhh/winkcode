# 😉winkcode

A coding agent CLI. Built-in tools (read, write, edit, grep, glob, exec), MCP, skills, session management, and context compaction. Windows only.

Basic functionality only. Still under development; not suitable for production use.

## Building

```bash
v .
```
or
```bash
v -prod .
```
